# 售后与退换货政策

本文件说明微商城售后与退换货规则。核心依据：《中华人民共和国消费者权益保护法》第二十五条、《网络购买商品七日无理由退货暂行办法》（2020年修订）、《消费者权益保护法实施条例》第十九条。

## 七日无理由退货（核心规则）

- 适用范围：消费者通过网络购买商品，自**签收商品次日**起七日内，有权无理由退货，无需说明理由。
- 七日如何计算：自消费者签收商品的**次日**开始起算，不是从下单付款日起算。
- 哪些商品**不适用**七日无理由退货：
  1. 消费者定作的商品（如定制服装、刻字商品）；
  2. 鲜活易腐的商品（如生鲜果蔬、鲜花绿植、活体水产）；
  3. 在线下载或消费者拆封的音像制品、计算机软件等数字化商品；
  4. 交付的报纸、期刊。
- 经购买时确认可不适用的情况：
  1. 拆封后易影响人身安全或生命健康、或易导致商品品质改变的商品；
  2. 一经激活或试用后价值贬损较大的商品（如激活过的手机）；
  3. 销售时已明示的临近保质期商品、有瑕疵的商品。
- 商品完好标准：退回商品应保持原有品质和功能，商品本身、配件、商标标识齐全。消费者基于查验需要打开包装、合理调试，不影响商品完好的，仍可退货。

## 商品不完好的判定

- 食品（含保健食品）、化妆品、医疗器械等：必要的一次性密封包装被损坏；
- 电子电器类：未经授权维修、改动，破坏/涂改强制性产品认证标志、序列号，有明显使用痕迹或产生激活、授权信息、个人数据留存；
- 服装、鞋帽、箱包、玩具、家纺、家居类：商标标识被摘除/剪断，商品受污、受损。

## 退货程序

1. 消费者自收到商品之日起七日内向商家发出退货通知；
2. 商家提供真实准确的退货地址、联系人、联系电话；
3. 消费者将商品本身、配件及赠品一并退回，保留退货凭证；
4. 商品完好的，商家应在收到退回商品之日起七日内返还已支付的商品价款；
5. 退款按原支付方式返还；使用积分、代金券、优惠券支付的，以相应形式返还。

## 运费与退货费用

- 无理由退货产生的退回运费依法由消费者承担；经营者与消费者另有约定的按约定执行。
- 商品存在质量问题（不符合质量要求）退货的，经营者应承担运输等必要费用。

## 质量问题与瑕疵

- 经营者提供的商品不符合质量要求的，消费者可依法退货、更换或要求修理；经营者应承担运输等必要费用。
- 平台商品均承诺正品保障、七天无理由退换、极速发货。

## 维权渠道

- 若与商家就退换货发生争议，可先通过平台退货通道申请并请求平台介入调解；
- 协商不成可拨打 12315 热线或通过全国 12315 平台投诉举报；
- 消费者应诚信行使无理由退货权利，不得恶意退货、损坏商品。
